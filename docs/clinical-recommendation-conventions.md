# Guideline recommendations and local evidence appraisal

Keep three concepts separate: the source guideline recommendation and its strength, this project’s certainty appraisal of the evidence, and the proposed local action. A low evidence grade does not automatically make a guideline recommendation optional. If a local action differs, name the actual difference, the reason and the pending or approved decision. Source quotations must retain the source’s own wording and grade.

Resolved factual corrections and allocation criteria are reference records, not votes. Local implementation within a guideline is different from an experimental expansion. Current high-risk proposals remain unactivated unless their own governance record establishes approval.
