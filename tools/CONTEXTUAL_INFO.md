# Contextual explanation display

The 25 October 2026 interface is a progressive enhancement loaded by `assets/portal-navigation.js`. `assets/contextual-copy.js`, `contextual-info.js` and `.css` serve the 12 cancer roadmaps and 7 transplant pathways. They retain full source text while displaying reviewed concise wording; clinical data and decision rules are unchanged. Older browsers retain native disclosures. The copy asset must load before the enhancement script.

Keep selection criteria, essential question help, timing/ordering, action conditions, safety warnings and proposed/closed high-risk statuses on the page. Selected assistant definitions and full Avoid wording remain inline. The second pass has 46 heading records, 63 help records and 46 longer recommendation summaries. Some short or sensitive help is deliberately verbatim. `tools/build_contextual_copy.py` contains the reviewed display wording and generates exact source guards. A changed source falls back to its full original; do not regenerate guards without reviewing the changed source. This is not keyword-based automatic summarization.

Question summaries open full explanations and associated sources. Source authority remains visible (policy, guidance, cohort, etc.). The repeated usage notes are consolidated into one control. Selected numeric definitions, dropdown choices, safety lists and next-action conditions are never collapsed by this layer. The original HCC waitlist enhancement sentence remains verbatim pending separate content reconciliation; the pre-existing HCA ≥5 cm versus adenoma >5 cm wording was also not harmonized by this presentation change.

Native Popover API on desktop; modal dialogue sheet on phone. Tap is primary, long press optional on information buttons only. Keyboard Enter/Space and Escape work. `ContextualInfo.handleHistory` integrates phone Back dismissal with the transplant renderer; `sourceOrigin` restores focus after reading a source. Roadmap reference chips dismiss the information sheet and focus the evidence-library entry. Do not remove these integration hooks during regeneration.

Reading mode expands full explanations in place of their short summaries. Print also expands checklists, definitions and discussion questions, then restores their previous state. Original information remains in the DOM. No patient selections or new preferences are saved.

After a legacy rebuild, follow `V12_REBUILD.md` and preserve the current shared renderer and all three contextual assets. Do not regenerate V12 content from stale procedural data. Use the current portal-navigation cache key (`20261025-flow1`). Run all V12/routing/roadmap tests plus `node tools/test_contextual_info.cjs`. Browser validation includes all 46 decisions and 103 topics, desktop/mobile interaction, source navigation and selected high-risk/safety cases. Analyst B's design and wording review, the corrections and reconciliation are stored in the local Contextual_Explanations_Review_2026-10-25/second-pass folder.

The layered decision interface now supersedes the former preset/disclosure behavior. See [DECISION_LAYERS.md](DECISION_LAYERS.md); use cache version `20261025-layers1`.
